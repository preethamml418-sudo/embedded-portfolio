## Projects

### 1. Basic Calculator
**Location:** `01-basic-calculator/`

A simple calculator program written in C that performs basic arithmetic operations.

#### Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division (with zero division check)
- Clean formatted output
- User-friendly prompts

#### How to Compile & Run

**On Windows (using GCC):**
```bash
gcc 01-basic-calculator/preetham.c -o calculator.exe
calculator.exe
```

**On Linux/Mac:**
```bash
gcc 01-basic-calculator/preetham.c -o calculator
./calculator
```

#### Usage
1. Enter the first number
2. Enter an operator (+, -, *, /)
3. Enter the second number
4. See the result!

#### Example
```
enter number 1 = 10
enter operation = +
enter number 2 = 5
Result = 15.000000
```
